# Astolfo Mod

A parody-themed Fabric mod for Minecraft 1.21.1, built around a large Astolfo-styled menu, custom HUD themes, and lots of cosmetic QoL toggles.

Features
- K key opens the menu
- Large horizontal-style module list
- Multiple HUD themes: Red, Black, Blue, Galaxy, Pink, Neon
- Glassy UI panels and dark premium theme
- No water fog / no lava fog / other cosmetic visual toggles
- Singleplayer parody test menu aesthetic

Quick start
1. Install Java 21
2. Run `./gradlew build`
3. Use the jar in `build/libs/`
4. Put it in your Fabric 1.21.1 mods folder

Notes
- This is intentionally a cosmetic parody mod and UI-focused menu.
- For a real transparent portrait, place your PNG at `src/main/resources/assets/astolfo_mod/textures/gui/astolfo_corner.png` and wire it into the menu renderer.
